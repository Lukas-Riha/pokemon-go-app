## Vyhledávání

Create a premium, realistic high fidelity UX design proposal board for the existing Czech Pokémon GO Atlas web app. Wide landscape canvas 1800x1100, left 72% desktop application, right 25% mobile screen, no physical device bezel. Main screen is Vyhledávání Pokémonů. Midnight navy background #061526, thin slate borders, white readable clean sans-serif, restrained electric blue active controls, subtle atmospheric blue forest illustration only at bottom of left desktop sidebar. Professional functional product UI, flat crisp straight-on screen, not a glowing fantasy poster. Desktop sidebar 190px with small Pokéball logo Pokémon GO Atlas and entries Přehled, Pokémoni, Kalendář, Vyhledávání active, Tahák, Rozpočet. Search field Eevee plus clear x, compact single horizontal identity strip Eevee sprite, Normal tag, text Hodnocení druhu. Small link Základní statistiky instead of tall stat bars. Clear horizontal section tabs Využití active, Typy, Evoluce, Můj kus. Below show compact role tabs PvP active, Raidy, Gym, Mega, Max, and league pills Little, Great active, Ultra, Master. Main table occupies most viewport with title Výsledky pro Great League, columns Druh, Pořadí druhu, Útoky. Three beautifully spacious but compact rows with recognizable Umbreon, Sylveon and Eevee small artwork, corresponding Dark Fairy Normal color chips, rank placeholder em dash, attacks link Otevřít rozbor. Above table subtle inline note Pořadí druhu není IV rank tvého kusu. Right side slim secondary card Evoluční možnosti with Eevee and 4 evolution icons, link Všechny evoluce, and a CLOSED disclosure Referenční CP. No fabricated game scores or recommendation percentages. On mobile same hierarchy: compact brand header, Vyhledávání title, Eevee search, compact Eevee identity row, tabs Využití Typy Evoluce Můj kus (scrollable), PvP/Raidy/Gym role controls, Great league selected. Three vertical compact result rows Umbreon, Sylveon, Eevee visible, each image name type and Otevřít rozbor. Mobile bottom five navigation items Přehled Pokémoni Hledání Kalendář Více. At bottom of board caption NÁVRH UI • ILUSTRAČNÍ OBSAH. Make typography clear, coherent, generous within compact information structure. Nothing is a screenshot of implemented work, this is a design concept.
